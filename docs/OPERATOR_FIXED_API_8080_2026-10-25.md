# 운영자09~13 API 서버8080 고정

2026-10-25 · 사용자 요청에 따라 운영자 API는 `http://127.0.0.1:8080`으로 고정했다.

- 프런트 주소는 기존 `http://127.0.0.1:5176/operator.html`이다.
- OperatorApp은 공통 `VITE_API_BASE_URL`을 사용하지 않는다. intake용18080 시연 빌드 변수와 분리했다.
- 로그인·고급설정의 서버 주소는 읽기 전용이다. 고급설정 버튼은 같은 서버를 새로 조회한다.
- 고정 모드에서는 외부 reconnect 호출로도 다른 서버로 전환되지 않고 기존 세션을 유지한다.
- 지표 C16의 ADMIN Basic 연결은 유지한다. 이번 수정은 지표 자동 로그인·인증 통합이 아니다.
- 기존18080 모의 백엔드와 USER/LAWYER 시연 설정·DB·키·서버 프로세스는 변경하지 않았다.

검증: 운영자 테스트57개 통과(고정 모드에서 로그인 입력·reconnect를 통한18080 전환 거부 포함), Vite 빌드 통과. 공통 환경변수를18080으로 주고 빌드해도 운영자 진입 번들에는8080만 포함됨을 확인했다.8080 health200,5176→8080 로그인 CORS preflight200도 확인했다.

5176에서 제공하는 운영자 HTML·자산을 갱신하고 실제 브라우저 새로고침 후 `API 서버 · 8080 고정`·읽기 전용8080 주소를 확인했다. 실제8080 로그인·지표 인증 제출은 이번 검증에 포함하지 않았다. 기존 세션은 메모리 방식이므로 새로고침 후 다시 로그인한다.

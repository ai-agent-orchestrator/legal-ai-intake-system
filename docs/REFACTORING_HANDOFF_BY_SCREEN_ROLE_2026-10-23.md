### C01. 공통 API 전달·오류 처리 / 화면03·07·08

- [x] **C01-a · 요청 키와 버전 전달**

  - `create`, `updateStatus`, `createMemo`에 계약의 키/버전 전달 경로 추가. 기존 다른 GET/파일/로그인 요청의 동작은 유지.
  - 키 형식은 서버와 일치. 빈 키를 임의 고정 문자열로 대체하지 않음. version0은 정상값이고 음수·NaN·누락을 최신값으로 추정하지 않음.

- [x] **C01-b · 구조화된409 오류 보존**

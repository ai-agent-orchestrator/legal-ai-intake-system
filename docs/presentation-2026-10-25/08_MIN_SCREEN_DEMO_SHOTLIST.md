## 2. 촬영 원칙

- 각 실험에 **실험 번호·제목 / 입력 조건 / 결과 / 지표·정산 / 모드**를 고정 자막으로 붙입니다.
- 앱에서 제공하는 기능은 실제 화면에서 조작합니다. 보안·비용 API 실험은 Postman 또는 기존 PowerShell 결과 화면과 C16 지표를 함께 녹화합니다. 앱에 없는 AI 입력 화면을 임의로 연출하지 않습니다.
- 짧은 정상 사용 흐름은 끊기지 않게 보여주고, 같은 유형의 반복 실험은 분할 화면으로 비교합니다. 코드·상태·비용 값은 정지 또는 확대 컷으로 읽을 시간을 줍니다.
- 원본 실험의 긴 대기만 줄입니다. 화면에 `기록 재생`·`대기 구간 편집`을 표시하고 과거 결과를 방금 실행한 것으로 설명하지 않습니다.
- 모든 실험 유형은 아래 커버리지 표에 연결합니다. 수백 개 자동 테스트의 개별 실행 전체는 원본 로그에 남기고, 영상에는 유형별 조건·결과와 검증 요약을 표시합니다.
- 화면 하단에 `모의 공급자`, `실제 LLM·모의 Guard`, `과거 기록 재생`, `마케팅 더미`를 해당 장면에 맞게 표시합니다.
- 키·Authorization 값·개인 사례는 녹화하지 않습니다. 실제 OpenAI 요청을 반복해 비용 제한을 소진하는 시연은 하지 않습니다.

## 02. 필수 오류 검증은 여섯 장면이면 충분합니다

상태 코드와 사용자가 다음에 할 행동을 같이 보여줍니다.

### 400 | 잘못된 입력
필수값 누락·100자 초과·잘못된 코드. 요청은 저장되지 않으며 필드를 수정합니다.

### 401 | 로그인 없음·만료
보호 경로에서 중단. 비밀번호 실패 후 입력 비움, 만료 후 내부 화면 제거, 새로고침 시 재로그인 안내.

### 403·404 | 자료 경계
다른 USER·미배정 LAWYER의 문의/파일은403. 본인 문의에 다른 파일ID를 끼우면404.

### 409 | 같은 키·다른 본문 / 버전 충돌
자동 덮어쓰기 대신 최신 상태 확인. 메모·선택 항목을 보존하고 명시적으로 편집을 재개합니다.

### 출력 차단·공급자 오류
생성 원문을 그대로 보내지 않고 안전 응답. 이미 수행한 단계는 정산하며 실패했다고 비용을0으로 만들지 않습니다.

### 예산 차단
테스트 세션 예산을 작게 둔 모의 호출로 재현. 실제 과금을 반복해 한도를 태우는 방식으로 시연하지 않습니다.

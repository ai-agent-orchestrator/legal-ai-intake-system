# PM · 제품 · 보안과 비용

2026-10-25 / 발표·녹화용 현행 요약. 원문 Ground Rule 및 현행 코드·검수 결과 기준.

## 01. 상담은 더 명확하게. AI 운영은 더 안심되게.

Security-Aware Legal AI Intake System

### 문제에서 시작한 Technical PM
고객의 법률 탐색 부담과 소규모 사무소의 초기 응대 비용을 함께 줄이는 서비스 흐름을 설계했습니다.

### 핵심 가치
짧은 문의 → 규칙·DB 기반 안내 → 자료 준비 → 공개 정보 검색 → 변호사 검토 → 관리자 관측.

### 오늘 보여줄 증거
역할별 권한, 6개 보안 통제, 6개 비용 통제, 직관적인 화면13, PC·390px 반응형 검수.

> 2026-10-25 발표본 | 촬영 DB는 더미. 공급자 응답·usage는 모의이며 실제 청구 증거가 아닙니다.

## 02. 누구의 어떤 비용을 줄이나

기능 나열보다 문제 → 판단 → 운영 지표를 연결합니다.

### 의뢰인
내 사건이 어떤 유형인지, 어떤 자료가 필요한지 모르기 쉽습니다. 선택형 입력과 짧은 안내로 시작 부담을 낮춥니다.

### 변호사
상담 전에 사건 유형·당사자 위치·자료·희망 도움을 구조화해 확인합니다. 내부 검토 메모는 의뢰인과 분리합니다.

### 사무소 관리자
접수 현황·관심 분야·보안·비용을 한 흐름에서 확인합니다. 복잡한 지표를 위험 패턴과 조치 후보로 바꿉니다.

### PM의 검증 기준
접수·검색·상담 준비 수는 확인 가능한 지표입니다. 상담 전환율 향상이나 시간 절감의 실증 수치는 아직 주장하지 않습니다.

## 03. 의뢰인에서 운영자까지, 하나의 여정

초반 안내에 매번 LLM을 부르지 않는 선택도 제품 설계입니다.

### 화면01~04 | USER
로그인 → 100자 이내 사건 입력 → 규칙 분류·Reference 안내 → 접수. 같은 저장 시도에는 같은 요청 키를 사용합니다.

### 화면05 | 공개 정보 탐색
저장 조건 → LLM 검색문 → 네이버의 변협 대상 + 일반 웹 검색 → 결과 저장 → 근거 범위 내 관련성 설명.

### 화면06~08 | LAWYER
배정 목록 → 상세 → 상태·내부 메모. 버전 충돌409를 알리고 작성 내용은 보존한 뒤 명시적으로 복구합니다.

### 화면09~13 | ADMIN
운영 요약·마케팅·보안/비용·Incident·AI 위험 요약. 문의 배정은 ADMIN, 내부 메모는 담당자와 관리자만 접근합니다.

> 변협은 네이버 인덱스의 공식 도메인 대상 검색입니다. 직접 변협 DB 조회·검증된 추천 순위가 아닙니다.

## 04. 보안6단계 | 여섯 가지 통제

모든 API에 여섯 단계를 무조건 적용한다는 의미는 아닙니다.

### 01 인증·업무 권한
JWT로 사용자 식별. 문의 소유자·배정 변호사·관리자를 서버에서 확인. 운영 업무는 ADMIN, 지표는 별도 Basic.

### 02 입력 계약
필수값·100자 사건 입력·코드·파일 유형·위험 URL을 서버에서 검증. 잘못된 입력은 저장 전에 중단.

### 03 Fixed Guard
법률 위해·탈옥·주입·비밀 요청·인증 우회를 규칙으로 먼저 차단. 이 경로에서는 LLM 생성을 호출하지 않음.

### 04 Dynamic Guard
요청 신호 조합과 대화 누적을 나란히 관찰. 요청 80점은 차단 권고, 누적 100점 등은 세션 제한.

### 05 입력·출력 Guardrail
생성 전 입력과 생성 후 출력을 검사. 이미 실행한 유료 단계 비용은 차단돼도 정산 대상.

### 06 개인정보 출력 보호
응답과 SSE 전송 전에 패턴 마스킹. 내부 상담 메모는 의뢰인 응답 JSON에서 제외.

> 업무 API는 인증·소유자·입력 정책, AI 생성 경로는 Fixed/Dynamic·입출력 Guard·Privacy를 적용합니다. 비용 검사는 각 유료 호출 앞에 끼워집니다.

## 05. 비용6단계 | 호출 전부터 종료까지

Guardrail 사용 비용도 공통 예산 장부에 포함합니다.

### 01 입력 범위 제한
사건 입력 100자. 입력 문자 수와 과금 토큰 수는 서로 다름. 시스템 지시문·검색 결과도 토큰에 포함.

### 02 출력 토큰 상한
생성 max_completion_tokens를 제한하고 최대 출력량으로 예약. 원격 Guard 출력 상한은 별도 확인 필요.

### 03 단계별 단가·예약
입력 Guard / 생성 / 출력 Guard / 검색문 / 설명 단계를 분리. 각 모델의 1,000토큰당 단가 적용.

### 04 공통 예산 확인
정산액 + 추정 사용액 + 진행 예약 + 신규 예약을 월(현재 프로세스 누적)·일·세션 한도와 비교. 부족하면 다음 호출 중단.

### 05 한 번만 정산·해제
usage 확인 시 토큰 기준, 실행 후 usage 미확인은 추정 정산. 미실행 예약만 해제. 중복 콜백 종료 방지.

### 06 관측·대사
C16에서 실사용·추정·정산·예약·단계 비용 확인. 공급자 청구서는 별도 대조하며 재시작 영속 원장은 아님.

> 소스 기본: 월 $2 / 일 $0.50 / 세션 $0.12, 생성 상한 2,048. 촬영 전용: 생성256 / 세션$0.003. 모의 usage와 실제 청구를 구분합니다.

## 06. 화면13: 지표를 운영 언어로

“무슨 수치인가?”에서 “무엇을 확인할까?”로.

### Dynamic Guard 1 | 요청 단위
차단행동 반복 시도 / 위험행동 반복 / 외부전송 위험 재시도를 색으로 구분. 결합 발생 건수와 작은 시계열을 함께 봅니다.

### Dynamic Guard 2 | 대화 단위
사유별 누적 점수·세션 차단 상태를 별도로 표시. 두 점수를 더하지 않으며, 누적값은 서버 메모리 기준입니다.

### 오해하지 않는 판정
요청 80점은 서버 위험 판정의 차단 권고입니다. 실제 도구 실행 차단·데이터 유출 확정이 아니며 Trace와 Incident를 검토합니다.

### 관측 연결
앱 MeterRegistry → C16 /actuator/prometheus → 기존 Prometheus 수집 → guardtimeseries → 화면13. C17 위험 이력으로 상세를 연결합니다.

> 그래프는 실제 Prometheus가 수집한 시계열입니다. 오늘 시계열의 발생 원천은 명시된 더미·모의 요청입니다.

## 07. 관리자가 바로 읽는 AI 위험 요약

요청별 위험과 대화 누적을 나란히, 조치 후보와 근거를 함께.

> 시연 더미·모의 요청 → 실제 앱 Metric → 기존 Prometheus 수집 → 실제 화면13. 위험 후보를 보여주며 유출 확정이나 자동 도구 실행 차단을 뜻하지 않습니다.

## 08. 누구나 이해할 수 있게, 권한은 분명하게

화면을 쉽게 만드는 일과 데이터를 안전하게 나누는 일을 함께 설계했습니다.

### USER
본인 문의만 조회. 다른 의뢰인의 상세·검색·파일은403, 내부 메모는 화면 숨김에 그치지 않고 JSON에서도 제외.

### LAWYER
배정된 문의만 열람·저장. 배정 회수 후403이며 기존 내부 편집 화면도 제거됩니다.

### ADMIN
전체 현황·배정·내부 업무 확인. USER/LAWYER 계정으로 운영자 로그인하면 거절합니다.

### 모바일
화면01~08을390px 브라우저에서 검수. 화면 이동·입력·충돌 안내를 확인했으며 실제 휴대폰/LAN 접속 검수는 별도입니다.

> 홍보 문구: 고객은 쉽게 설명하고, 변호사는 빠르게 파악하고, 관리자는 위험과 비용을 한눈에 봅니다.

## 09. 작동을 넘어, 멈춰야 할 때 멈추는가

Ground Rule: 정상 · 실패 · 차단 · 사유 · 관측까지 한 묶음으로 검증합니다.

### 이번 검수
Q01 역할 교차 시나리오14개 통과. 화면01~08 PC·390px 및 충돌/재로그인 레이아웃10개. 보안·비용·검색95개·프런트201개·시연 필수15개 통과.

### 실제로 고친 문제
로그아웃·계정 변경 후 남던 검색 필터를 초기화했습니다. 새로고침으로 메모리 로그인이 풀리는 이유를 명시했습니다.

### 현재 가능한 시연
더미 문의10건, 저장된 검색 실행/설명, 담당자 검토, 위험 이력과 실제 수집 그래프, 정상·차단·오류·비용 모의 검증.

### 아직 실측이 아닌 것
실제 OpenAI 연결·검색 품질·청구 확인은 사용자와 Claude가 진행합니다. 현재 발표 자료는 모의 검증이며 실제 결과가 확인되면 해당 컷만 교체합니다.

> 마무리: “AI를 붙이는 데서 끝내지 않고, 서비스가 안전하게 운영되는 방식까지 설계했습니다.”

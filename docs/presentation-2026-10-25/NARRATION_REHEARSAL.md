# 무음 리허설에 붙일 내레이션 초안

기존78초 무음 리허설용 초안입니다. 최신 화면 시연은 [완료분6분30초 편집본](06M30_COMPLETED_ONLY_DEMO.md)을 사용합니다. 보안·관리자 장면은 이번 편집에서 제외했습니다. PDF·PM 설명은 영상 밖에서 진행합니다.

## 01 오프닝

처음 법률 문제를 겪는 고객은 무엇부터 설명해야 할지 막막합니다. 저는 고객과 사무소의 문제를 서비스 흐름, 보안 정책, 운영 지표로 연결하는 Technical PM 관점에서 이 서비스를 설계했습니다.

## 02 고객 접수

고객이 사건을 짧게 설명하면 접수 정보와 준비할 자료로 연결합니다. 초반 안내는 규칙과 저장된 절차 정보를 사용해, 매번 원문을 LLM에 보내지 않습니다.

## 03 공개 정보 탐색

필요한 탐색 단계에서는 저장 조건으로 검색문을 만듭니다. 변협 도메인 대상과 일반 웹의 출처를 구분하고, 같은 요청 번호로 결과와 관련성 설명을 다시 확인합니다. 지금 화면은 명시된 모의 검색입니다.

## 04 변호사 업무

변호사는 배정된 문의를 검토하고 내부 메모를 남깁니다. 메모는 의뢰인 응답에서 제외됩니다. 동시 수정이 발생해도 작성 내용을 보존하고, 최신 상태를 확인한 뒤 저장합니다.

## 05 오류·보안·비용

다른 의뢰인의 자료는 서버에서 차단합니다. 위험 요청과 예산 초과는 생성 전에 중단합니다. 보안 여섯 가지 통제와 Guard 비용을 포함한 예약·정산으로, 정상 동작뿐 아니라 안전하게 멈추는 흐름까지 검증했습니다.

## 06 관리자·모바일·종료

관리자는 화면13에서 반복 패턴과 시계열, 요청 위험과 대화 누적을 나란히 확인합니다. 같은 접수 흐름을 좁은 모바일 화면에서도 사용할 수 있습니다.

AI를 붙이는 데서 끝내지 않고, 서비스가 안전하게 운영되는 방식까지 설계했습니다. 상담은 더 명확하게, AI 운영은 더 안심되게. 이 리허설은 더미와 모의 공급자 시연이며 실제 LLM 연결은 별도 확인합니다.

## 편집 도구

무음 원본과 장면 클립은 WebM/VP8이다. Microsoft는 Clipchamp 권장 입력 형식으로 `.webm`을 명시한다. 가져온 뒤 발표자 음성·자막을 붙이고 최종 MP4로 내보낸다.

# 화면10 마케팅 시연 분석 — 구현·검수

## 구현 범위

기존 화면10 메뉴·배너·남색 사이드바·흰 패널과 실제 집계 영역을 유지했다. 자료 선택 버튼으로 **실제 집계 / 시연 분석**을 전환한다. 초기 진입은 실제 집계이며, 새로고침·재진입 때도 자동으로 시연 실적을 표시하지 않는다.

- 실제 집계: 기존 C13 `GET /api/admin/dashboard/marketing-funnel` 계약·집계·오류 처리를 사용한다.
- 시연 분석: 프런트의 가상 문의 40건을 계산한다. API·DB·실제 LLM 설정 변경 없음.
- 로그인과 관리자 접근 경계는 기존 운영자 인증을 유지한다.
- 실제 자료와 가상 자료를 같은 카드에 섞지 않는다. ‘시연 데이터 기준’, 접수 기간·기준일, 실제 분석 미연결 범위를 명시한다.

## 화면 구성

| 영역 | 표시 내용 |
|---|---|
| 요약 | 문의 40건 · 상담 완료 12건 · 수임 4건 · 상담 후 수임률 33.3% |
| 전환 퍼널 | 접수 40 → 변호사 검색 24 → 상담 완료 12 → 수임 확정 4 |
| 직전 단계 도달률 | 60% / 50% / 33.3% |
| 핵심 인사이트 | 상담 후 수임률, 미도달 비율이 가장 큰 구간과 건수 |
| 미수임 사유 | 비용 부담 4건(50%) · 분야 불일치 2건(25%) · 연락 두절 2건(25%) |
| 운영 제안 | 최다 미수임 사유에 따라 점검할 내용 표시. LLM 없이 규칙으로 생성 |

수임률의 분모는 상담 완료 12건이며, 미수임 사유의 분모는 확정된 미수임 8건이다. 접수·검색 단계의 미도달은 진행 중도 포함하므로 확정 이탈로 단정하지 않는다. 분모 0은 `—`, 관측된 0%는 `0%`로 구분한다.

## 더미 데이터와 계산

`src/operator/marketingDemo.js`의 문의별 고유 ID, 단계별 도달 시각, 상담 결과·결과 시각·미수임 사유를 사용한다. 접수 기간은 2026.10.01–10.07, 기준일은 2026.10.25인 고정된 예시다. 날짜 선택 기능이나 기간 비교 기능을 구현한 것은 아니다.

- 단계 도달은 문의별 1건으로 집계해 동일 단계 이벤트 중복으로 건수를 늘리지 않는다.
- 중복 문의 ID, 이전 단계가 없는 진행, 수임/미수임 결과와 단계의 모순은 거부한다.
- 상담 후 결과 대기와 확정 미수임을 구분한다.
- 문의 결과를 바꾸면 비율·미수임 사유·인사이트 입력도 함께 바뀐다. 완성된 비율 숫자를 화면에 고정해 놓은 방식이 아니다.
- 합성 ID와 선택형 사유만 있으며 실제 이름·연락처·사건 원문이 없다. 기존 C13 DTO에 필드를 추가하지 않았다.

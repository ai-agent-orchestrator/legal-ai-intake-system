## 3. Separate framework / external / planned scope

- Additional configured Actuator request patterns: GET `/actuator/health`, `/actuator/info`, `/actuator/metrics`, `/actuator/metrics/{metricName}`. C16 Prometheus is already listed above. See the auxiliary checklist for public vs ADMIN Basic rules.
- Direct NeMo contracts: POST `/v1/input-rails/check` and `/v1/output-rails/check` on `guardrails.base-url`. These belong to another server and bypass application cost reservations when called directly.
- P03 proposed POST `/api/intakes/search-requests/{searchRequestId}/execute` remains design-only; it is not part of the 65 Controller routes or 36 implemented numbered entries.
- Optional framework discovery, health subpaths, H2 console/UI and implicit HEAD/OPTIONS are not counted as declared Controller APIs. Do not infer that this inventory enumerates every framework URL.

## 실제 호출까지 남은 최소 항목

- [ ] **키 인증·사용 가능한 모델 확인:** 로컬 PowerShell에서 아래 도구 실행. 키는 가려진 입력란에만 붙여 넣는다. 성공 시 Windows 사용자 전용 암호화 파일과 키 없는 모델 목록 결과만 로컬에 저장한다. 모델 목록에 있다고 실제 생성 권한/잔액까지 확인된 것은 아니다.

```powershell
powershell.exe -NoProfile -File "C:\myLectureWs\legal-ai-intake-security-server\scripts\Set-LocalOpenAiKey.ps1"
```

- [ ] **접근 가능한 저가 모델·단가 확정:** 현재 소스는 gpt-4o-mini, 입력/출력은1,000토큰당$0.00015/$0.00060이다. 다른 모델을 선택하면 그 모델의 실제 요금으로 변경하고 실행 설정을 대조한다. 계정 권한을 확인하기 전에는 최저가 모델이 연결됐다고 판정하지 않는다. [공식 mini 요금](https://developers.openai.com/api/docs/models/gpt-4o-mini).
- [ ] **프로젝트 잔액·실행 한도·중단 대상 확인:** 학원 프로젝트의 잔액과 오늘 사용 범위, 실제 실행 서버의 모델·단가·토큰 상한·예산·예약 기준값 확인. 첫 시험은 짧은 요청1건·동시 실행1개·자동 반복 없이 진행한다.
- [ ] **짧은 정상 생성1회:** 실제 응답·반환 모델·usage·정산/예약 종료를 확인하고 공급자 사용량과 대조한다. 이 단계가 끝나야 연결 성공으로 판정한다.

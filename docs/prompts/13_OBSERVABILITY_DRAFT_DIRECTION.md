# 화면13 디자인 시안 · 화면12 공통 디자인 적용

2026-10-22. 사용자 첨부 화면12와 직전 화면13의 두 패널 구성을 기준으로 만든 시안을 확정해 실제 React·API 연결에 적용했다. 현재 경로는 `operator.html#/observability`다.

![화면13 확정 디자인 · 모의 검수 자료](../../output/obs13-prometheus/screen13-preview.png)

## 화면12와의 공통 디자인

- 같은 법률 상담 사진의 낮은 상단 배너, 흰 브랜드·관리자 영역, 남색 사이드바와 파란 활성 메뉴.
- 사진 아래 흰 작업 표면에 경로·큰 제목·설명·조회 시각·버튼을 배치한다.
- 화면12처럼 두 개의 흰 패널, 얇은 파랑 회색 테두리, 아이콘을 포함한 제목 행, 작은 상태 배지를 사용한다.
- 기존 React의 `BrandMark`, `Icon`을 재사용한다. 새로운 인물·배경 사진은 생성하지 않는다.

## 직전 화면13 방향 유지

| 위치 | 시안 구성 |
|---|---|
| 왼쪽 한 패널 | **Dynamic Guard 1 · 위험 행동 반복 시도**. 파랑/초록/빨강 카드3개를 작게 묶는다. |
| 카드1 파랑 | 차단 행동 반복 시도 · 같은 기록의 정책 위반+재시도 패턴 건수 하나와 실제 Prometheus 시계열 선 그래프 |
| 카드2 초록 | 위험 행동 반복 · 같은 기록의 도구 오류+재시도 패턴 건수 하나와 실제 Prometheus 시계열 선 그래프 |
| 카드3 빨강 | 외부 전송 위험 재시도 · 같은 기록의 외부 접근+재시도 패턴 건수 하나와 실제 Prometheus 시계열 선 그래프 |
| 각 카드 왼쪽 | 같은 요청의 행동 점수 + 재시도 점수 = 총점. **80점 이상 차단 권고**와 관련 이력 번호. |
| 오른쪽 패널 | **Dynamic Guard 2 · 대화 누적 제한**. 이전 초록 디자인의 방패·큰 누적 점수·100점 기준·누적 흐름을 살리고 사유별 점수표를 바로 보여준다. |
| 하단 작은 영역 | 요청 점수·대화 누적·운영자 확인 순서를 세 칸으로 설명한다. 자세한 계산 기준도 화면13 안에서 펼쳐 본다. 화면14는 폐지했다. |

요청 점수는 최대100이며 80점 이상은 차단·상위 검토 **권고**다. 대화 누적 점수는 100점을 넘을 수 있고 100점 또는 별도 반복 기준 도달 시 **실제 이용 제한**이다. 두 점수·서로 다른 요청을 합산하지 않는다. 시안의 ‘위험 행동 반복’31점 예시는 차단으로 꾸미지 않고 도구 점검으로 표시한다.

## 자료·연결 범위

- 기존 C16 `GET /actuator/prometheus`와 C17 `GET /api/agent/risk/history`를 사용할 화면이라는 계약은 유지한다. C16은 현재 값, C17은 건수·점수로 유지하며 신규 보조 Actuator GET /actuator/guardtimeseries로 실제 시계열을 연결한다. DB 변경은 없다.
- 위 스크린샷은 승인 당시 가상 자료다. 현재 실제 React 화면은 C16/C17을 읽고 반복 패턴 기록 건수·요청 점수와 Prometheus의 시간별 증가량을 표시한다.
- 지표 연결은 기존 ADMIN Basic 모달, 새로고침은 C16/C17·신규 시계열 조회를 사용하고 실제 모드에서30초 자동 갱신을 제공한다. AI 생성·외부 검색은 실행하지 않는다.
- 실제 관측이 없으면 —로 표시하고 빈 기록·조회 오류·재연결을 구분한다. 시안 캡처를 실제 관측 결과로 설명하지 않는다.
